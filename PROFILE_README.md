# Hi, I'm Nitin 👋

**Student researcher · Microbiology · Environmental biotechnology**

I'm exploring how bacteria can help treat domestic and municipal wastewater. Alongside my research, I'm learning to build practical Python tools that make measurements easier to check, analyze, and communicate.

The question that connects my work: **How can we turn microbial processes into useful, well-supported solutions for cleaner water?**

### What I'm working on

🦠 **Microbial wastewater treatment** — understanding bacterial communities and treatment performance.

📊 **Reproducible analysis** — organizing measurements, checking assumptions, and keeping calculations traceable.

📚 **Reading the evidence** — connecting published research with clearly documented questions and limitations.
